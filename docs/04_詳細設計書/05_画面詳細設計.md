## 5.2 主要画面詳細

### 5.2.1 ダッシュボード (S-002)

**目的**: 本日の予約状況と売上を一目で把握

**コンポーネント構成**:
```
Dashboard
├── TodayAppointments    # 本日の予約リスト
├── SalesSummary         # 売上サマリー
├── NextCustomerCard     # 次の顧客情報
└── RecentSimulations    # 最近のシミュレーション
```

**データ取得**:
```typescript
// ダッシュボードデータ取得
const { data } = useQuery({
  queryKey: ['dashboard', today],
  queryFn: () => fetchDashboardData(today),
});
```

### 5.2.2 顧客カルテ (S-004)

**目的**: 顧客の全情報を一元表示

**タブ構成**:
1. 基本情報
2. 髪質プロファイル
3. 施術履歴
4. 写真
5. シミュレーション

**アラート表示**:
- アレルギー情報は赤色背景で目立つように表示
- 最終来店から90日以上経過している場合は注意表示

### 5.2.3 シミュレーション (C-004)

**フロー**:
1. 写真選択/撮影
2. スタイル選択
3. 合成実行（ローディング表示）
4. 結果表示（Before/After比較）
5. 保存/共有

**状態管理**:
```typescript
interface SimulationState {
  step: 'photo' | 'style' | 'processing' | 'result';
  customerPhoto: string | null;
  selectedStyle: HairStyle | null;
  result: SimulationResult | null;
  progress: number;
}
```
