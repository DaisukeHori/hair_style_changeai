# 第6章 バッチ処理設計

## 6.1 定期バッチ一覧

| バッチ名 | 実行タイミング | 処理内容 |
|---------|--------------|---------|
| 予約リマインダー | 毎日 9:00 | 翌日の予約者にリマインド通知 |
| 来店促進通知 | 毎週月曜 10:00 | 60日以上来店なしの顧客に通知 |
| 古いシミュレーション削除 | 毎日 3:00 | 24時間経過した一時画像を削除 |
| 統計データ集計 | 毎日 2:00 | 日次売上・来店統計を集計 |

## 6.2 実装

### 6.2.1 予約リマインダー

```typescript
// supabase/functions/reminder-batch/index.ts

import { serve } from 'https://deno.land/std/http/server.ts';
import { createClient } from '@supabase/supabase-js';

serve(async () => {
  const supabase = createClient(
    Deno.env.get('SUPABASE_URL')!,
    Deno.env.get('SUPABASE_SERVICE_ROLE_KEY')!
  );

  const tomorrow = new Date();
  tomorrow.setDate(tomorrow.getDate() + 1);
  const tomorrowStr = tomorrow.toISOString().split('T')[0];

  // 翌日の予約を取得
  const { data: appointments } = await supabase
    .from('appointments')
    .select(`
      *,
      customers(first_name, last_name, email, line_id),
      stylists(name)
    `)
    .eq('appointment_date', tomorrowStr)
    .eq('status', 'confirmed')
    .eq('reminder_sent', false);

  for (const apt of appointments || []) {
    // 通知送信（メールまたはLINE）
    if (apt.customers.email) {
      await sendEmailReminder(apt);
    }
    if (apt.customers.line_id) {
      await sendLineReminder(apt);
    }

    // 送信済みフラグを更新
    await supabase
      .from('appointments')
      .update({ reminder_sent: true })
      .eq('id', apt.id);
  }

  return new Response(JSON.stringify({ processed: appointments?.length }));
});
```
