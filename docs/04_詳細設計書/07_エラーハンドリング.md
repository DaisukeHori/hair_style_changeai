# 第7章 エラーハンドリング

## 7.1 エラー分類

| カテゴリ | 例 | 対応 |
|---------|-----|------|
| ネットワーク | タイムアウト、オフライン | リトライ、オフライン通知 |
| 認証 | 期限切れ、権限なし | 再ログイン誘導 |
| バリデーション | 入力エラー | フィールドエラー表示 |
| ビジネス | 予約重複 | ユーザーに選択肢提示 |
| システム | サーバーエラー | エラー画面、サポート連絡 |

## 7.2 実装

### 7.2.1 エラー境界

```typescript
// src/components/ErrorBoundary.tsx
import { Component, ErrorInfo, ReactNode } from 'react';
import * as Sentry from '@sentry/react';

interface Props {
  children: ReactNode;
  fallback?: ReactNode;
}

interface State {
  hasError: boolean;
  error: Error | null;
}

export class ErrorBoundary extends Component<Props, State> {
  state: State = { hasError: false, error: null };

  static getDerivedStateFromError(error: Error): State {
    return { hasError: true, error };
  }

  componentDidCatch(error: Error, errorInfo: ErrorInfo) {
    Sentry.captureException(error, { extra: errorInfo });
  }

  render() {
    if (this.state.hasError) {
      return this.props.fallback || (
        <div className="flex flex-col items-center justify-center min-h-screen">
          <h1 className="text-2xl font-bold text-gray-900 mb-4">
            エラーが発生しました
          </h1>
          <p className="text-gray-600 mb-6">
            申し訳ございません。問題が発生しました。
          </p>
          <button
            onClick={() => window.location.reload()}
            className="px-4 py-2 bg-primary-600 text-white rounded-lg"
          >
            再読み込み
          </button>
        </div>
      );
    }
    return this.props.children;
  }
}
```

### 7.2.2 APIエラーハンドリング

```typescript
// src/services/api/errorHandler.ts

export const handleApiError = (error: unknown): never => {
  if (error instanceof ApiError) {
    switch (error.code) {
      case 'PGRST301': // JWT expired
        throw new AuthError('セッションが期限切れです');
      case '23505': // Unique violation
        throw new ValidationError('このデータは既に存在します');
      case '23503': // Foreign key violation
        throw new ValidationError('関連データが存在しません');
      default:
        throw error;
    }
  }
  throw new Error('予期しないエラーが発生しました');
};
```

### 7.2.3 トースト通知

```typescript
// エラー発生時の通知
const toast = useToast();

try {
  await saveCustomer(data);
  toast.success('保存しました');
} catch (error) {
  if (error instanceof ValidationError) {
    toast.error('入力エラー', error.message);
  } else {
    toast.error('保存に失敗しました');
    Sentry.captureException(error);
  }
}
```
