# 第10章 コーディング規約

## 10.1 全般

### 命名規則

| 対象 | 規則 | 例 |
|------|------|-----|
| コンポーネント | PascalCase | `CustomerCard.tsx` |
| 関数 | camelCase | `getCustomers()` |
| 定数 | UPPER_SNAKE | `MAX_RETRY_COUNT` |
| 型/Interface | PascalCase | `Customer`, `ApiResponse` |
| ファイル（コンポーネント以外） | camelCase | `formatDate.ts` |

### ディレクトリ構造

```
src/
├── components/
│   ├── common/      # 共通UI
│   ├── customer/    # 顧客関連
│   ├── style/       # スタイル関連
│   └── layout/      # レイアウト
├── hooks/           # カスタムフック
├── services/        # API/外部サービス
├── stores/          # Zustand
├── types/           # 型定義
├── utils/           # ユーティリティ
└── pages/           # ページコンポーネント
```

## 10.2 TypeScript

### 型定義

```typescript
// ❌ Bad
const customer: any = await getCustomer(id);

// ✅ Good
const customer: Customer = await getCustomer(id);

// インターフェース定義
interface Customer {
  id: string;
  first_name: string;
  last_name: string;
  phone?: string;
}

// Propsの型定義
interface CustomerCardProps {
  customer: Customer;
  onClick?: () => void;
  showAlerts?: boolean;
}
```

### Nullチェック

```typescript
// ❌ Bad
customer.phone.substring(0, 3);

// ✅ Good
customer.phone?.substring(0, 3) ?? '';

// Optional Chaining + Nullish Coalescing
const displayName = customer?.nickname ?? `${customer.last_name} ${customer.first_name}`;
```

## 10.4 スタイリング (TailwindCSS)

### クラス順序

```tsx
// レイアウト → サイズ → 余白 → 背景 → ボーダー → テキスト → その他
<div className="
  flex items-center justify-between    // レイアウト
  w-full h-12                          // サイズ
  px-4 py-2                            // 余白
  bg-white                             // 背景
  border border-gray-200 rounded-lg    // ボーダー
  text-gray-900 font-medium            // テキスト
  hover:bg-gray-50 transition-colors   // インタラクション
">
```

### cn() ユーティリティ

```typescript
// src/utils/cn.ts
import { clsx, type ClassValue } from 'clsx';
import { twMerge } from 'tailwind-merge';

export const cn = (...inputs: ClassValue[]) => twMerge(clsx(inputs));

// 使用例
<button className={cn(
  'px-4 py-2 rounded-lg',
  variant === 'primary' && 'bg-primary-600 text-white',
  disabled && 'opacity-50 cursor-not-allowed',
  className
)}>
```

## 10.5 Git

### コミットメッセージ

```
<type>: <description>

# types
feat:     新機能
fix:      バグ修正
docs:     ドキュメント
style:    フォーマット
refactor: リファクタリング
test:     テスト
chore:    ビルド/ツール

# 例
feat: 顧客検索機能を追加
fix: カルテ保存時のバリデーションエラーを修正
docs: README更新
```

