# 第8章 テスト設計

## 8.1 テスト方針

| レベル | ツール | カバレッジ目標 |
|--------|--------|--------------|
| ユニットテスト | Vitest | 80% |
| コンポーネントテスト | Testing Library | 主要コンポーネント |
| E2Eテスト | Playwright | クリティカルパス |

## 8.2 テスト例

### 8.2.1 ユニットテスト

```typescript
// src/utils/__tests__/format.test.ts
import { describe, it, expect } from 'vitest';
import { formatPhoneNumber, formatDate } from '../format';

describe('formatPhoneNumber', () => {
  it('正しくフォーマットする', () => {
    expect(formatPhoneNumber('09012345678')).toBe('090-1234-5678');
  });

  it('nullの場合は空文字を返す', () => {
    expect(formatPhoneNumber(null)).toBe('');
  });
});

describe('formatDate', () => {
  it('日本語形式でフォーマットする', () => {
    expect(formatDate('2024-01-15')).toBe('2024年1月15日');
  });
});
```

### 8.2.2 コンポーネントテスト

```typescript
// src/components/customer/__tests__/CustomerCard.test.tsx
import { render, screen } from '@testing-library/react';
import { CustomerCard } from '../CustomerCard';

const mockCustomer = {
  id: '1',
  first_name: '花子',
  last_name: '山田',
  phone: '09012345678',
  visit_count: 10,
  hair_profile: { allergies: { items: ['ジアミン'] } },
};

describe('CustomerCard', () => {
  it('顧客名を表示する', () => {
    render(<CustomerCard customer={mockCustomer} />);
    expect(screen.getByText('山田 花子')).toBeInTheDocument();
  });

  it('アレルギーがある場合はバッジを表示', () => {
    render(<CustomerCard customer={mockCustomer} showAlerts />);
    expect(screen.getByText('アレルギー')).toBeInTheDocument();
  });
});
```

### 8.2.3 E2Eテスト

```typescript
// e2e/customer-flow.spec.ts
import { test, expect } from '@playwright/test';

test('顧客登録フロー', async ({ page }) => {
  await page.goto('/stylist/customers');

  // 新規登録ボタンクリック
  await page.click('button:has-text("新規登録")');

  // フォーム入力
  await page.fill('input[name="last_name"]', '山田');
  await page.fill('input[name="first_name"]', '花子');
  await page.fill('input[name="phone"]', '09012345678');

  // 保存
  await page.click('button:has-text("保存")');

  // 成功確認
  await expect(page.locator('text=登録しました')).toBeVisible();
});
```

## 8.3 テスト実行

```bash
# ユニット/コンポーネントテスト
npm run test

# カバレッジ付き
npm run test:coverage

# E2Eテスト
npm run test:e2e
```
