## 4.2 主要機能詳細

### 4.2.1 スタイルシミュレーション機能

**コア機能**: 顧客の写真に希望のヘアスタイルをAI合成

```
シミュレーションフロー
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Step 1: 顧客写真の準備
├── iPadカメラで撮影
└── 既存写真から選択

Step 2: スタイル選択
├── カテゴリから選ぶ（長さ/色/雰囲気）
├── Pinterest検索
├── おすすめから選ぶ（AIレコメンド）
└── お気に入りから選ぶ

Step 3: AI合成
└── NANOBANANA Proで高精度合成

Step 4: 結果確認
├── ビフォーアフター比較表示
├── スライダーで切り替え
└── 複数スタイルを並列比較

Step 5: 保存・共有
├── カルテに保存
├── お気に入り登録
└── 施術決定
```

**技術的特徴**:
- 顔認識による正確な位置合わせ
- 髪色・髪質を考慮した自然な合成
- 複数角度対応（正面・横・後ろ）
- リアルタイムプレビュー

### 4.2.2 デジタルカルテ機能

```

## 4.4 技術アーキテクチャ

### 4.4.1 技術スタック

| レイヤー | 技術 | 選定理由 |
|---------|------|---------|
| **フロントエンド** | React + TypeScript | 型安全、エコシステム |
| **スタイリング** | TailwindCSS | 高速開発、カスタマイズ性 |
| **状態管理** | Zustand | 軽量、React Native互換 |
| **データフェッチ** | TanStack Query | キャッシュ、リアルタイム |
| **モバイル** | React Native / Expo | コード共有、iPadネイティブ |
| **バックエンド** | Supabase | フルスタック、スケーラブル |
| **データベース** | PostgreSQL | 信頼性、RLS |
| **認証** | Supabase Auth | セキュア、簡単実装 |
| **ストレージ** | Supabase Storage | 画像管理、署名付きURL |
| **AI合成** | NANOBANANA Pro | 高精度ヘアスタイル合成 |

## 4.5 セキュリティ

### 4.5.1 セキュリティ対策

| 対策項目 | 実装方法 |
|---------|---------|
| **認証** | Supabase Auth（JWT） |
| **認可** | Row Level Security (RLS) |
| **通信暗号化** | HTTPS必須 |
| **画像保護** | 署名付きURL（有効期限付き） |
| **データ分離** | 店舗IDによるマルチテナント |
| **監査ログ** | 重要操作のログ記録 |

### 4.5.2 個人情報保護

```
個人情報保護対策
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 個人情報保護法準拠
