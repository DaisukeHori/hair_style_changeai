# 第2章 プロジェクト背景と目的

## 2.1 業界背景

### 2.1.1 美容業界の現状

日本の美容室は約25万店舗あり、競争が激化しています。

### 2.1.2 顧客の不満

美容室利用者へのアンケート調査で明らかになった主な不満：

| 順位 | 不満内容 | 割合 |
|------|---------|------|
| 1位 | 希望通りのスタイルにならなかった | 42% |
| 2位 | イメージが伝わらなかった | 38% |
| 3位 | 前回と同じにしてほしいのに違った | 28% |
| 4位 | 待ち時間が長い | 25% |
| 5位 | 自分に似合うスタイルがわからない | 22% |

## 2.2 課題の深掘り

### 2.2.1 コミュニケーションギャップ

```
現状のカウンセリングフロー

顧客: 「少し軽めにしてください」
        ↓
美容師: （軽めって何cm?どの部分?）
        ↓
施術後: 「思ったより短くなった...」
        ↓
     【顧客不満・クレーム・失客】
```

**問題の本質**: 言語だけでは髪型のイメージを正確に共有できない

### 2.2.2 カルテ管理の非効率

| 紙カルテの問題 | 影響 |
|---------------|------|
| 探すのに時間がかかる | 顧客待ち時間増加 |
| 字が読めない | 情報の損失 |
| 写真を貼れない | ビジュアル情報なし |
| 複数店舗で共有不可 | 店舗異動時に困る |
| 紛失・劣化リスク | 顧客データ消失 |

### 2.2.3 スタイル提案の限界

- 美容師の記憶・経験頼り
- スタイルブックは古くなる
- 顧客の顔で試せない
- 「似合うかどうか」は施術後までわからない

---

## 2.3 プロジェクトの目的

### 2.3.1 ミッション

> **「なりたい自分」を、施術前に可視化する**

### 2.3.2 ビジョン

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│   すべての美容室で、顧客が安心して「変われる」体験を提供    │
│                                                             │
│   AIの力で、美容師と顧客の創造的なコラボレーションを促進   │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 2.3.3 具体的な目標

| 目標カテゴリ | 具体的な目標 | KPI |
|-------------|-------------|-----|
| 顧客満足度 | イメージギャップの解消 | クレーム率 -50% |
| リピート率 | 再来店率の向上 | リピート率 +20% |
| 業務効率 | カルテ作業時間の削減 | 作業時間 -40% |
| 売上向上 | 追加メニュー提案の増加 | 客単価 +15% |

## 2.4 プロジェクトの範囲

### 2.4.1 対象範囲（スコープ）

**含まれるもの:**
- 顧客向けiPadアプリケーション
- 美容師向けiPadアプリケーション
- 管理者向けWebダッシュボード
- AIスタイルシミュレーション機能
- デジタルカルテシステム
- 予約管理機能
- Pinterest画像連携

**含まれないもの（将来検討）:**
- POSシステム連携
- 会計・決済機能
- 在庫管理
- 給与計算
