# 第4章 画面設計

## 4.1 画面設計方針

### 4.1.1 デザイン原則

| 原則 | 説明 |
|------|------|
| **シンプル** | 必要な情報のみ表示、余計な装飾を排除 |
| **一貫性** | 同じ操作は同じUIパターン |
| **フィードバック** | 操作結果を即座に視覚的に伝達 |
| **タッチ最適化** | 44px以上のタッチターゲット |
| **アクセシビリティ** | 高コントラスト、読みやすいフォント |
