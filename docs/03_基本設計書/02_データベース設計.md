# 第2章 データベース設計

## 2.1 設計方針

### 2.1.1 設計原則

| 原則 | 説明 |
|------|------|
| 正規化 | 第3正規形を基本とし、パフォーマンス要件に応じて非正規化 |
| 一貫性 | 命名規則、データ型の統一 |
| 拡張性 | JSONB型で柔軟なスキーマ拡張 |
| セキュリティ | RLS（Row Level Security）によるアクセス制御 |

### 2.1.2 命名規則

| 対象 | 規則 | 例 |
|------|------|-----|
| テーブル名 | snake_case、複数形 | customers, hair_styles |
| カラム名 | snake_case | first_name, created_at |
| 主キー | id (UUID) | id |
| 外部キー | {参照テーブル単数}_id | customer_id |
| 日時 | *_at | created_at, updated_at |
| フラグ | is_* / has_* | is_active, has_allergy |

## 2.3 テーブル定義

### 2.3.1 salons（美容室）

```sql
CREATE TABLE salons (
    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    name VARCHAR(100) NOT NULL,
    address VARCHAR(255),
    phone VARCHAR(20),
    email VARCHAR(255) UNIQUE,
    business_hours JSONB DEFAULT '{}',
    logo_url VARCHAR(500),
    settings JSONB DEFAULT '{}',
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- インデックス
CREATE INDEX idx_salons_email ON salons(email);

-- 更新トリガー
CREATE TRIGGER update_salons_updated_at
    BEFORE UPDATE ON salons
    FOR EACH ROW
    EXECUTE FUNCTION update_updated_at_column();
```

### 2.3.2 stylists（美容師）

```sql
CREATE TABLE stylists (
    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    salon_id UUID NOT NULL REFERENCES salons(id) ON DELETE CASCADE,
    auth_user_id UUID REFERENCES auth.users(id),
    name VARCHAR(50) NOT NULL,
    nickname VARCHAR(50),
    role VARCHAR(20) NOT NULL DEFAULT 'stylist'
        CHECK (role IN ('owner', 'manager', 'stylist', 'assistant')),
    profile_image_url VARCHAR(500),
    specialties JSONB DEFAULT '[]',
    bio TEXT,
    is_active BOOLEAN DEFAULT TRUE,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- インデックス
CREATE INDEX idx_stylists_salon_id ON stylists(salon_id);
CREATE INDEX idx_stylists_auth_user_id ON stylists(auth_user_id);
CREATE INDEX idx_stylists_is_active ON stylists(salon_id, is_active);
```

### 2.3.3 customers（顧客）

```sql
CREATE TABLE customers (
    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    salon_id UUID NOT NULL REFERENCES salons(id) ON DELETE CASCADE,
    customer_code VARCHAR(20) NOT NULL,
    first_name VARCHAR(50) NOT NULL,
    last_name VARCHAR(50) NOT NULL,
    first_name_kana VARCHAR(50),
    last_name_kana VARCHAR(50),
    gender VARCHAR(10) CHECK (gender IN ('male', 'female', 'other')),
    birth_date DATE,
    phone VARCHAR(20),
    email VARCHAR(255),
    line_id VARCHAR(100),
    address VARCHAR(255),
    occupation VARCHAR(50),
    referral_source VARCHAR(50),
    notes TEXT,
    profile_photo_url VARCHAR(500),
    last_visit_date DATE,
    visit_count INTEGER DEFAULT 0,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),

    UNIQUE(salon_id, customer_code)
);

-- インデックス
CREATE INDEX idx_customers_salon_id ON customers(salon_id);
CREATE INDEX idx_customers_name_kana ON customers(salon_id, last_name_kana, first_name_kana);
CREATE INDEX idx_customers_phone ON customers(salon_id, phone);
CREATE INDEX idx_customers_last_visit ON customers(salon_id, last_visit_date DESC);

-- 全文検索用
CREATE INDEX idx_customers_name_search ON customers
    USING gin(to_tsvector('japanese', last_name || ' ' || first_name));
```

## 2.4 Row Level Security (RLS)

### 2.4.1 RLSポリシー設計

```sql
-- RLS有効化
ALTER TABLE salons ENABLE ROW LEVEL SECURITY;
ALTER TABLE stylists ENABLE ROW LEVEL SECURITY;
ALTER TABLE customers ENABLE ROW LEVEL SECURITY;
ALTER TABLE visits ENABLE ROW LEVEL SECURITY;
-- ... 全テーブルに適用

-- ヘルパー関数: 現在のユーザーのsalon_idを取得
CREATE OR REPLACE FUNCTION get_user_salon_id()
RETURNS UUID AS $$
BEGIN
    RETURN (
        SELECT salon_id
        FROM stylists
        WHERE auth_user_id = auth.uid()
    );
END;
$$ LANGUAGE plpgsql SECURITY DEFINER;

-- customers テーブルのRLSポリシー
CREATE POLICY "Users can view customers in their salon"
    ON customers FOR SELECT
    USING (salon_id = get_user_salon_id());

CREATE POLICY "Users can insert customers in their salon"
    ON customers FOR INSERT
    WITH CHECK (salon_id = get_user_salon_id());

CREATE POLICY "Users can update customers in their salon"
    ON customers FOR UPDATE
    USING (salon_id = get_user_salon_id());

CREATE POLICY "Managers can delete customers in their salon"
    ON customers FOR DELETE
    USING (
        salon_id = get_user_salon_id()
        AND EXISTS (
            SELECT 1 FROM stylists
            WHERE auth_user_id = auth.uid()
            AND role IN ('owner', 'manager')
        )
    );
```

## 2.5 データベース関数

### 2.5.1 更新日時自動更新

```sql
CREATE OR REPLACE FUNCTION update_updated_at_column()
RETURNS TRIGGER AS $$
BEGIN
    NEW.updated_at = NOW();
    RETURN NEW;
END;
$$ LANGUAGE plpgsql;
```

### 2.5.2 顧客番号自動生成

```sql
CREATE OR REPLACE FUNCTION generate_customer_code()
RETURNS TRIGGER AS $$
DECLARE
    next_code INTEGER;
BEGIN
    SELECT COALESCE(MAX(CAST(SUBSTRING(customer_code FROM 2) AS INTEGER)), 0) + 1
    INTO next_code
    FROM customers
    WHERE salon_id = NEW.salon_id;

    NEW.customer_code = 'C' || LPAD(next_code::TEXT, 5, '0');
    RETURN NEW;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER set_customer_code
    BEFORE INSERT ON customers
    FOR EACH ROW
    WHEN (NEW.customer_code IS NULL)
    EXECUTE FUNCTION generate_customer_code();
```

### 2.5.3 来店回数・最終来店日更新

```sql
CREATE OR REPLACE FUNCTION update_customer_visit_stats()
RETURNS TRIGGER AS $$
BEGIN
    IF TG_OP = 'INSERT' AND NEW.status = 'completed' THEN
        UPDATE customers
        SET
            visit_count = visit_count + 1,
            last_visit_date = NEW.visit_date
        WHERE id = NEW.customer_id;
    END IF;

    IF TG_OP = 'UPDATE' AND OLD.status != 'completed' AND NEW.status = 'completed' THEN
        UPDATE customers
        SET
            visit_count = visit_count + 1,
            last_visit_date = NEW.visit_date
        WHERE id = NEW.customer_id;
    END IF;

    RETURN NEW;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER update_visit_stats
    AFTER INSERT OR UPDATE ON visits
    FOR EACH ROW
    EXECUTE FUNCTION update_customer_visit_stats();
```
