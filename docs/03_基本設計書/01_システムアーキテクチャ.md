### 1.1.2 設計原則

| 原則 | 説明 | 適用箇所 |
|------|------|---------|
| **関心の分離** | UI/ビジネスロジック/データを分離 | コンポーネント設計 |
| **単一責任** | 各モジュールは1つの責任のみ | 関数・コンポーネント |
| **DRY** | 重複コードの排除 | 共通コンポーネント |
| **型安全** | TypeScriptによる型チェック | 全コード |
| **疎結合** | モジュール間の依存を最小化 | サービス層 |

## 1.6 React Native移行考慮

### 1.6.1 プラットフォーム抽象化

```typescript
// プラットフォーム抽象化例

// 共通インターフェース
interface PlatformAdapter {
  storage: StorageAdapter;
  camera: CameraAdapter;
  navigation: NavigationAdapter;
}

// Web実装
const webAdapter: PlatformAdapter = {
  storage: localStorageAdapter,
  camera: webCameraAdapter,
  navigation: reactRouterAdapter,
};

// React Native実装
const nativeAdapter: PlatformAdapter = {
  storage: asyncStorageAdapter,
  camera: expoCameraAdapter,
  navigation: reactNavigationAdapter,
};
```

### 1.6.2 スタイリング戦略

| Web | React Native | 共通化戦略 |
|-----|-------------|-----------|
| TailwindCSS | NativeWind | 同一クラス名を使用 |
| CSS Modules | StyleSheet | デザイントークン共有 |
| rem/px | dp | 相対単位で統一 |
