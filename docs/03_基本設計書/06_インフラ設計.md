### 6.2.3 接続プール設定

```
PostgreSQL 接続設定

【Session Mode】(トランザクション用)
├── 接続文字列: postgresql://...?pgbouncer=true

├── 接続文字列: postgresql://...:6543/...
├── プールサイズ: 200
└── 用途: 通常のCRUD操作

【Direct Connection】(マイグレーション用)
├── 接続文字列: postgresql://...:5432/...
└── 用途: スキーマ変更、データ移行
```

### 6.6.2 復旧手順

```
復旧手順
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【データベース復旧】
1. Supabaseダッシュボードにログイン
2. Database > Backups
3. 復旧ポイントを選択

【アプリケーション復旧】
1. Vercelダッシュボードにログイン
2. Deployments > 正常なデプロイを選択
3. Promote to Production

【緊急時の切り戻し】
1. git revert で変更を取り消し
2. 強制デプロイ
3. Supabaseマイグレーションのロールバック
```

### 6.8.2 GitHub Actions

```yaml
# .github/workflows/ci.yml
name: CI

on:
  push:
    branches: [main, develop]
  pull_request:
    branches: [main]

jobs:
  lint-and-test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: '20'
          cache: 'npm'

      - run: npm ci
      - run: npm run lint
      - run: npm run typecheck
      - run: npm run test
      - run: npm run build
```
