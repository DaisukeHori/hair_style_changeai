## 4.2 Pinterest API連携

### 4.2.1 概要

| 項目 | 内容 |
|------|------|
| 連携目的 | ヘアスタイル画像の検索・取得 |
| APIバージョン | v5 |
| 認証方式 | OAuth 2.0 |
| 通信プロトコル | HTTPS |
| データ形式 | JSON |

### 4.2.2 使用エンドポイント

| エンドポイント | メソッド | 用途 |
|---------------|---------|------|
| /pins/search | GET | ピン検索 |
| /pins/{pin_id} | GET | ピン詳細取得 |
| /pins/{pin_id}/images | GET | 画像取得 |
| /boards | GET | ボード一覧取得 |

### 4.2.3 リクエスト/レスポンス仕様

**ピン検索リクエスト**:
```json
GET /v5/pins/search
Headers:
  Authorization: Bearer {access_token}

Query Parameters:
  query: "韓国風 ミディアム ヘアスタイル"
  page_size: 25
  bookmark: {pagination_token}
```

**ピン検索レスポンス**:
```json
{
  "items": [
    {
      "id": "pin_123456",
      "title": "韓国風レイヤーカット",
      "description": "...",
      "media": {
        "images": {
          "original": {
            "url": "https://...",
            "width": 1080,
            "height": 1350
          }
        }
      },
      "link": "https://pinterest.com/pin/...",
      "created_at": "2024-01-15T10:00:00Z"
    }
  ],
  "bookmark": "next_page_token"
}
```

### 4.2.4 制限事項

| 制限項目 | 値 |
|---------|-----|
| レート制限 | 1,000 req/hour |
| 検索結果上限 | 100件/リクエスト |
| 画像保存 | ローカル保存必須（直接リンク不可） |

### 4.2.5 エラーハンドリング

| HTTPステータス | 意味 | 対処 |
|---------------|------|------|
| 400 | リクエスト不正 | パラメータ確認 |
| 401 | 認証エラー | トークン更新 |
| 403 | アクセス拒否 | 権限確認 |
| 429 | レート制限 | リトライ（指数バックオフ） |
| 500 | サーバーエラー | リトライ |

## 4.3 NANOBANANA Pro API連携

### 4.3.1 概要

| 項目 | 内容 |
|------|------|
| 連携目的 | AIによるヘアスタイル合成 |
| APIバージョン | v1 |
| 認証方式 | APIキー |
| 通信プロトコル | HTTPS |
| データ形式 | JSON |

### 4.3.2 使用エンドポイント

| エンドポイント | メソッド | 用途 |
|---------------|---------|------|
| /api/v1/simulate | POST | スタイル合成 |
| /api/v1/detect-face | POST | 顔検出 |
| /api/v1/status/{job_id} | GET | 処理状況確認 |
| /api/v1/result/{job_id} | GET | 結果取得 |

### 4.3.3 スタイル合成リクエスト/レスポンス

**リクエスト**:
```json
POST /api/v1/simulate
Headers:
  Authorization: Bearer {api_key}
  Content-Type: application/json

Body:
{
  "source_image": {
    "url": "https://storage.example.com/customer_photo.jpg",
    "type": "customer"
  },
  "style_image": {
    "url": "https://storage.example.com/style_123.jpg",
    "type": "hairstyle"
  },
  "options": {
    "preserve_hair_color": false,
    "blend_intensity": 0.9,
    "output_format": "png",
    "output_size": {
      "width": 1024,
      "height": 1024
    }
  },
  "callback_url": "https://api.example.com/webhook/simulation"
}
```

**レスポンス（同期）**:
```json
{
  "status": "processing",
  "job_id": "job_abc123",
  "estimated_time_seconds": 5
}
```

**レスポンス（完了時）**:
```json
{
  "status": "completed",
  "job_id": "job_abc123",
  "result": {
    "image_url": "https://api.nanobanana.pro/results/job_abc123.png",
    "expires_at": "2024-01-15T11:00:00Z",
    "metadata": {
      "face_detected": true,
      "confidence_score": 0.95,
      "processing_time_ms": 4200
    }
  }
}
```

### 4.3.4 顔検出リクエスト/レスポンス

**リクエスト**:
```json
POST /api/v1/detect-face
Headers:
  Authorization: Bearer {api_key}

Body:
{
  "image_url": "https://storage.example.com/photo.jpg"
}
```

**レスポンス**:
```json
{
  "faces": [
    {
      "bounding_box": {
        "x": 100,
        "y": 50,
        "width": 200,
        "height": 250
      },
      "landmarks": {
        "left_eye": {"x": 140, "y": 120},
        "right_eye": {"x": 220, "y": 120},
        "nose": {"x": 180, "y": 160},
        "mouth": {"x": 180, "y": 200}
      },
      "confidence": 0.98
    }
  ],
  "image_size": {
    "width": 720,
    "height": 960
  }
}
```

### 4.3.5 制限事項

| 制限項目 | 値 |
|---------|-----|
| レート制限 | 100 req/min |
| 画像サイズ上限 | 10MB |
| 対応形式 | JPEG, PNG, WebP |
| 結果保持期間 | 1時間 |

### 4.3.6 エラーハンドリング

| エラーコード | 意味 | 対処 |
|-------------|------|------|
| FACE_NOT_DETECTED | 顔検出失敗 | 写真の撮り直しを促す |
| MULTIPLE_FACES | 複数の顔を検出 | 顔の選択を促す |
| STYLE_INCOMPATIBLE | スタイル適用不可 | 別スタイルを提案 |
| PROCESSING_FAILED | 処理エラー | リトライ |
| RATE_LIMITED | レート制限 | 待機後リトライ |
