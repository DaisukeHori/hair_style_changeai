# 第1章 システム概要

## 1.1 システム名称

**Hair Style Change AI**（ヘアスタイルチェンジAI）

---

## 1.2 システムの目的

本システムは、美容室における以下の課題を解決することを目的とする。

| 課題 | 解決策 |
|------|--------|
| ヘアスタイルのイメージ共有が困難 | AIシミュレーションによる視覚化 |
| 紙カルテによる非効率な顧客管理 | デジタルカルテによる一元管理 |
| 施術履歴の記録・参照の困難さ | 写真付き施術記録の蓄積 |
| 顧客体験の差別化不足 | インタラクティブなスタイル提案 |

---

## 1.3 システムの範囲

### 1.3.1 対象業務

```
対象業務範囲
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【顧客管理業務】
├── 顧客情報の登録・更新・検索
├── 髪質・頭皮プロファイル管理
├── 来店履歴管理
└── お気に入りスタイル管理

【施術業務】
├── カウンセリング支援
├── スタイルシミュレーション
├── 施術内容の記録
├── ビフォーアフター写真管理
└── 次回施術提案

【予約管理業務】
├── 予約受付・変更・キャンセル
├── スケジュール管理
└── リマインダー通知

【分析・レポート業務】
├── 売上集計
├── 顧客分析
└── スタイル人気分析
```

### 1.3.2 対象外業務

以下の業務は本システムの対象外とする：

- 会計・決済処理（POSシステム連携は将来検討）
- 在庫管理
- 給与計算・勤怠管理
- 外部予約サイト連携（ホットペッパービューティー等）

| 指標 | 目標値 |
