## 2.2 F1: 認証・認可機能

### F1.1 ログイン機能

| 項目 | 内容 |
|------|------|
| **機能ID** | F1.1 |
| **機能名** | ログイン |
| **概要** | 美容師がシステムにログインする |
| **アクター** | スタイリスト、マネージャー、オーナー |
| **優先度** | 必須 |

**入力項目**:
| 項目名 | データ型 | 必須 | 備考 |
|--------|---------|:----:|------|
| メールアドレス | string | ○ | メール形式 |
| パスワード | string | ○ | 8文字以上 |

**処理内容**:
1. 入力バリデーション
2. Supabase Authで認証
3. JWTトークン発行
4. セッション開始
5. ダッシュボードへリダイレクト

**出力**:
- 成功: ダッシュボード画面表示
- 失敗: エラーメッセージ表示

**例外処理**:
| エラー条件 | 対応 |
|-----------|------|
| 認証失敗 | 「メールアドレスまたはパスワードが正しくありません」 |
| アカウント無効 | 「このアカウントは無効化されています」 |
| 連続失敗5回 | 10分間ロック |

### F1.2 ログアウト機能

| 項目 | 内容 |
|------|------|
| **機能ID** | F1.2 |
| **機能名** | ログアウト |
| **概要** | システムからログアウトする |

**処理内容**:
1. セッション終了
2. トークン無効化
3. ログイン画面へリダイレクト

## 2.3 F2: スタイル管理機能

### F2.1 スタイル検索機能

| 項目 | 内容 |
|------|------|
| **機能ID** | F2.1 |
| **機能名** | スタイル検索 |
| **概要** | ヘアスタイル画像を条件で検索する |
| **アクター** | 顧客、スタイリスト |
| **優先度** | 必須 |

**検索条件**:
| 条件名 | データ型 | 説明 |
|--------|---------|------|
| キーワード | string | フリーワード検索 |
| 髪の長さ | enum | short/medium/long |
| 髪色 | string[] | 複数選択可 |
| 顔型 | enum | 丸/面長/卵型/ベース/逆三角 |
| 性別 | enum | male/female/unisex |
| タグ | string[] | ボブ、レイヤー等 |

**表示項目**:
- サムネイル画像
- スタイル名
- タグ
- お気に入り数
- ソート（人気順/新着順）

**ページネーション**:
- 1ページ20件
- 無限スクロール対応

### F2.3 Pinterest連携機能

| 項目 | 内容 |
|------|------|
| **機能ID** | F2.3 |
| **機能名** | Pinterest連携 |
| **概要** | Pinterestからヘアスタイル画像を検索・取り込む |
| **アクター** | マネージャー、オーナー |
| **優先度** | 高 |

**処理フロー**:
```
Pinterest連携フロー
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. キーワード入力
   └── 例: "韓国風 ミディアム ヘアスタイル"

2. Pinterest API検索
   └── 画像一覧取得

3. 画像プレビュー表示
   └── 取り込み対象を選択

4. メタデータ入力
   ├── タイトル
   ├── タグ
   ├── 髪の長さ
   └── 髪色

5. 画像保存
   ├── Supabase Storageに保存
   └── DBにメタデータ登録
```

## 2.4 F3: シミュレーション機能

### F3.1 写真撮影/選択機能

| 項目 | 内容 |
|------|------|
| **機能ID** | F3.1 |
| **機能名** | 写真撮影/選択 |
| **概要** | シミュレーション用の顧客写真を準備する |
| **アクター** | 顧客、スタイリスト |
| **優先度** | 必須 |

**写真取得方法**:
1. iPadカメラで撮影
2. カルテから既存写真を選択
3. 端末の写真ライブラリから選択

**写真要件**:
| 項目 | 要件 |
|------|------|
| 解像度 | 720x720px以上 |
| 形式 | JPEG, PNG |
| サイズ | 10MB以下 |
| 顔の向き | 正面推奨 |

**顔検出処理**:
- 顔が検出できない場合はエラー表示
- 複数の顔が検出された場合は選択を促す

### F3.2 スタイル合成機能

| 項目 | 内容 |
|------|------|
| **機能ID** | F3.2 |
| **機能名** | スタイル合成 |
| **概要** | NANOBANANA Proで顧客写真にヘアスタイルを合成 |
| **アクター** | システム（自動） |
| **優先度** | 必須 |

**処理フロー**:
```
合成処理フロー
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[入力]
├── 顧客写真URL
└── スタイル画像URL
        │
        ▼
[NANOBANANA Pro API呼び出し]
├── 顔検出・位置合わせ
├── ヘアスタイル抽出
├── 合成処理
└── 結果画像生成
        │
        ▼
[出力]
├── 合成結果画像URL
└── 処理ステータス
```

**API仕様**（NANOBANANA Pro）:
```json
// リクエスト
POST /api/v1/simulate
{
  "source_image": "顧客写真URL",
  "style_image": "スタイル画像URL",
  "options": {
    "preserve_color": false,
    "blend_mode": "natural"
  }
}

// レスポンス
{
  "status": "success",
  "result_image": "合成結果画像URL",
  "processing_time_ms": 1500
}
```

### F3.3 結果表示機能

**表示モード**:
1. **ビフォーアフター**: スワイプで切り替え
2. **スライダー**: 左右にスライドして比較
3. **並列表示**: 2枚を横に並べて表示
4. **複数比較**: 複数スタイルを一覧表示
