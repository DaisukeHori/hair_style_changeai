# 第7章 用語定義

## 7.1 業務用語

### 7.1.1 美容業界用語

| 用語 | 英語表記 | 定義 |
|------|---------|------|
| カルテ | Customer Card | 顧客の基本情報・施術履歴・髪質情報などを記録したもの |
| スタイリスト | Stylist | 美容師免許を持ち、施術を行う美容師 |
| アシスタント | Assistant | スタイリストの補助を行うスタッフ |
| カウンセリング | Counseling | 施術前に顧客の希望や状態を確認する相談 |
| 施術 | Service/Treatment | カット、カラー、パーマなどの美容作業 |
| リタッチ | Retouch | 根元の伸びた部分のみをカラーリングすること |
| ハイライト | Highlight | 部分的に明るい色を入れるカラー技法 |
| レイヤー | Layer | 髪に段をつけるカット技法 |
| ダメージレベル | Damage Level | 髪の傷み具合を表す指標（1〜5） |
| 白髪率 | Gray Hair Percentage | 白髪の割合（%） |

### 7.1.2 施術関連用語

| 用語 | 説明 |
|------|------|
| フルカラー | 髪全体を染めるカラーリング |
| グラデーション | 毛先に向かって色が変化するカラー技法 |
| インナーカラー | 髪の内側だけを染めるカラー技法 |
| コールドパーマ | 薬剤のみでかけるパーマ |
| デジタルパーマ | 熱を加えてかけるパーマ |
| エアウェーブ | 温風でかけるパーマ |
| トリートメント | 髪に栄養を与えるケア施術 |
| ヘッドスパ | 頭皮マッサージ・クレンジング |

## 7.2 システム用語

### 7.2.1 技術用語

| 用語 | 英語表記 | 定義 |
|------|---------|------|
| API | Application Programming Interface | システム間でデータをやり取りする仕組み |
| RLS | Row Level Security | 行単位でデータアクセスを制御するセキュリティ機能 |
| JWT | JSON Web Token | 認証情報を含むトークン形式 |
| CRUD | Create, Read, Update, Delete | データの基本操作（作成・読取・更新・削除） |
| SaaS | Software as a Service | クラウドでソフトウェアを提供する形態 |
| マルチテナント | Multi-tenant | 複数の顧客（店舗）が同一システムを共有する構成 |

### 7.2.2 画像処理用語

| 用語 | 説明 |
|------|------|
| シミュレーション | 顧客の写真にヘアスタイルを合成すること |
| 顔検出 | 画像から顔の位置を検出する処理 |
| ランドマーク | 顔のパーツ（目、鼻、口など）の座標 |
| 合成 | 2つ以上の画像を組み合わせて新しい画像を作成すること |
| バウンディングボックス | 検出した顔を囲む矩形領域 |

### 7.2.3 Supabase関連用語

| 用語 | 説明 |
|------|------|
| Supabase | PostgreSQLベースのBaaS（Backend as a Service） |
| Edge Functions | サーバーレスで実行される関数 |
| Storage | ファイル保存サービス |
| Realtime | リアルタイムデータ同期機能 |
| 署名付きURL | 有効期限付きの一時的なアクセスURL |
