# 第6章 制約条件と前提条件

## 6.1 技術的制約

### 6.1.1 プラットフォーム制約

| 制約項目 | 内容 | 理由 |
|---------|------|------|
| フロントエンド | React + TypeScript | React Native移行を考慮 |
| バックエンド | Supabase | 開発効率・コスト |
| データベース | PostgreSQL | Supabase標準 |
| ホスティング | Vercel | Reactとの親和性 |
| モバイル | Expo / React Native | クロスプラットフォーム |

### 6.1.2 外部API制約

```
外部API制約一覧
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【Pinterest API】
├── レート制限: 1,000 req/hour
├── 画像直接埋め込み: 不可（保存必須）
├── 商用利用: 利用規約確認必要
└── API変更: 予告なく変更の可能性

【NANOBANANA Pro API】
├── レート制限: 100 req/min
├── 画像サイズ: 10MB以下
├── 処理時間: 最大15秒
├── 結果保持: 1時間
└── 料金体系: 従量課金（確認必要）

【Supabase】
├── 接続プール: プランにより制限
├── ストレージ: プランにより制限
├── Edge Functions: 実行時間制限あり
└── Realtime: 同時接続数制限
```

### 6.1.3 ブラウザ・OS制約

| 制約項目 | 対応範囲 |
|---------|---------|
| 対応ブラウザ | Safari (iPadOS), Chrome, Edge, Firefox 最新2バージョン |
| 対応OS | iPadOS 15.0以降 |
| 画面サイズ | iPad (768px以上) 最適化 |
| オフライン | 一部機能のみ対応 |

## 6.3 法的・規制制約

### 6.3.1 個人情報保護

| 制約項目 | 対応内容 |
|---------|---------|
| 個人情報保護法 | プライバシーポリシー策定・同意取得 |
| 利用目的明示 | 収集時に利用目的を明示 |
| 第三者提供 | 原則禁止、同意なしでの提供不可 |
| 開示請求 | 本人からの請求に対応 |
| 漏洩時対応 | 通知義務・報告義務 |

## 6.6 リスクと対策

### 6.6.1 技術リスク

| リスク | 発生確率 | 影響度 | 対策 |
|--------|:--------:|:------:|------|
| API仕様変更 | 中 | 高 | 抽象化レイヤー設計 |
| サービス停止 | 低 | 高 | 代替サービス調査 |
| パフォーマンス問題 | 中 | 中 | 負荷テスト実施 |
| セキュリティ脆弱性 | 低 | 高 | 定期セキュリティレビュー |

### 6.6.2 業務リスク

| リスク | 発生確率 | 影響度 | 対策 |
|--------|:--------:|:------:|------|
| 導入抵抗 | 中 | 中 | 丁寧なオンボーディング |
| 操作ミス | 中 | 低 | 確認画面・取消機能 |
| データ入力負担 | 中 | 中 | UI最適化・省入力化 |

### 6.6.3 法的リスク

| リスク | 発生確率 | 影響度 | 対策 |
|--------|:--------:|:------:|------|
| 個人情報漏洩 | 低 | 高 | セキュリティ対策強化 |
| 著作権侵害 | 低 | 中 | 利用規約確認・ガイドライン |
| 肖像権問題 | 低 | 中 | 同意取得フロー整備 |
